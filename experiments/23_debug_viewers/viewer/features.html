PCA: the first 3 principal components of a feature set as RGB (per frame: fitted on this frame; global: one basis per feature set from 2 frames of each scene, so colours are comparable across frames). Similarity: click any image; every panel shows the cosine similarity (0 → black, 1 → white) of the feature at that point to all features, optionally of another frame. Grey: no depth. DINO and the patch-pooled Sonata are at patch resolution (42×75), Sonata stages at pixel resolution (168×300) — a stage token covers about 8 / 16 / 32 cm.
